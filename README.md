# PulseFolio — Real-Time Portfolio Tracker

A live portfolio tracker with simulated stock prices, a watchlist, and gain/loss indicators, built to explore push-based real-time updates without the UI thrashing under frequent price changes.

## Stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **Real-time:** Socket.io

## The Problem

Real-time price feeds update frequently — if every tick triggers a full re-render across the UI, the interface starts to feel laggy and janky well before the data volume is actually large. The challenge isn't getting live data to the client; it's doing so without unnecessary re-renders and network overhead.

## The Approach

- **Push-based updates via Socket.io** — the server emits price ticks to connected clients; no client-side polling or repeated fetch requests.
- **Throttled socket emissions** — the server batches/limits how often it emits updates per symbol, instead of pushing on every single price change.
- **Memoized frontend components** — price/watchlist components are memoized (`React.memo` / `useMemo`) so only the components whose values actually changed re-render.
- **Simulated price feed** — prices are generated by a simple mock generator (e.g. random walk per symbol) server-side. This is explicitly a simulation, not a real market data integration.

## Features

- [ ] Live-updating simulated stock prices (Socket.io push)
- [ ] Watchlist — track multiple simulated holdings
- [ ] Gain/loss visual indicators per holding
- [ ] Throttled updates + memoized rendering to prevent UI thrash

## Getting Started

### Prerequisites

- Node.js (v18+)

### Setup

```bash
git clone https://github.com/harry3201/pulsefolio.git
cd pulsefolio

# backend
cd server
npm install
npm run dev

# frontend
cd ../client
npm install
npm start
```

### Environment Variables

```
PORT=5000
SOCKET_EMIT_INTERVAL_MS=1000   # throttle window for price emissions
```
